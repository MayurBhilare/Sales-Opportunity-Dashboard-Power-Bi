# Sales Opportunity Dashboard | Power BI

## 📊 Project Overview

An interactive **Power BI Sales Opportunity Dashboard** developed to analyze sales opportunities, opportunity value, win/loss performance, win rate, and conversion rate. The dashboard provides both management-level insights and detailed opportunity-level analysis.

## 🎯 Objectives

- Monitor overall sales opportunity performance
- Track won and lost opportunities and opportunity value
- Analyze win rate and conversion rate
- Understand opportunity distribution across different sales stages
- Compare performance across sales channels and countries
- Identify the Top 5 Salespersons
- Drill down into individual sales opportunities

## 📌 Dashboard Features

### Key Performance Indicators

- Total Opportunities
- Won Opportunities
- Lost Opportunities
- Total Opportunity Value
- Won & Lost Opportunity Value
- Win Rate
- Conversion Rate

### Visual Analysis

- Win Rate doughnut chart
- Conversion Rate doughnut chart
- Opportunities by Sales Stage
- Opportunities by Sales Channel
- Country-level opportunity mapping
- Top 5 Salesperson performance table

### Detailed Opportunity View

The detailed salesperson-level view includes:

- Customer Name
- Opportunity ID
- Opportunity Value
- Country
- Sales Channel
- Sales Stage
- Close Date
- Reporting Date
- Deal Status

## 🛠️ Tools & Skills Used

- **Power BI Desktop**
- DAX Measures
- Data Visualization
- KPI Development
- Interactive Filters & Slicers
- Sales Funnel Analysis
- Business Intelligence Reporting

## 📈 Dashboard Insights

The dashboard enables users to:

- Evaluate the overall sales pipeline
- Identify won and lost opportunity trends
- Monitor sales conversion performance
- Compare salesperson performance
- Analyze sales channel performance
- Understand geographical distribution of opportunities
- Track opportunities across different sales stages
- Review individual opportunities for detailed follow-up
